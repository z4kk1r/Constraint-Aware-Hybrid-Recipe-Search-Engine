# Constraint-Aware-Hybrid-Recipe-Search-Engine
Built an open-source, constraint-aware recipe search engine over 60,000 Food.com recipes using Qdrant hybrid retrieval (bge-small-en-v1.5 dense + BM25 sparse vectors), strict in-index payload filtering for hard dietary/time constraints (gluten_free, halal_friendly, vegan, nut_free), ingredient-coverage reranking, and an interactive Gradio web demo.
